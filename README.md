# ♟️ ChessNova

### A New Era of Chess.

**ChessNova** is a modern, interactive chess game designed for chess lovers. Play against an AI-powered computer opponent or challenge a friend on the same device. Enjoy multiple difficulty levels, smooth animations, sound effects, and an installable offline experience.

---

## 🚀 Features

- ♟️ **Play Against Computer** – Challenge the built-in chess AI.
- 👥 **Two-Player Mode** – Play with a friend on the same device.
- 🧠 **Three Difficulty Levels** – Choose Easy, Medium, or Hard.
- ♔ **Interactive Chessboard** – Move pieces with simple clicks.
- ⚔️ **Chess Rules** – Supports legal moves, castling, en passant, and pawn promotion.
- 👑 **Game Status** – Check, checkmate, stalemate, and draw detection.
- ↩️ **Undo Move** – Take back your previous move.
- 🔄 **Flip Board** – Change the board orientation.
- 🔊 **Sound Effects** – Audio feedback for moves, captures, checks, and promotions.
- 🌙 **Theme Switching** – Switch between light and dark themes.
- 📱 **Responsive Design** – Play on desktop, tablet, and mobile.
- 📲 **Installable PWA** – Add ChessNova to your device's home screen.
- 📴 **Offline Support** – Play offline after the application has been cached.

## 💻 Run Locally

**Option 1: Directly in your browser**

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. Start playing ChessNova.

**Option 2: Using VS Code**

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

For PWA installation and service-worker offline support, run the application through HTTPS or localhost.

## 📲 Install ChessNova

ChessNova supports installation as a Progressive Web App.

1. Open ChessNova in a supported browser.
2. Select the **Install App** option when available.
3. Alternatively, use your browser's **Add to Home Screen** option.
4. Launch ChessNova directly from your device.

## 🌐 Deploy on GitHub Pages

1. Push your project to GitHub.
2. Open your repository.
3. Navigate to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
